Incola is an Australian startup that helps tenants to pay security deposits easily. The tenant can pay back to Incola in easy instalments.

### Role

UX & UI Designer

Incola requires User Experience design and the User Interface design for the user end application where the user will apply for Incola to get the security deposit.

### Approach

Started off with User Research for the product and its viability check. Once the results have arrived, I gathered the responses into consideration to design the user flows and the customer journey for the SaaS model for rentals application.

A rough sketch of wireframes is drawn and analysed to understand and design the functions of a user and also defined the information architecture.

The user application will have 7 screens during on-boarding and 3 pages on the dashboard with multiple states.
